01 Be the stranger

Someone's escrow has expired. You've never touched it. Send it home.

If the person an escrow depends on is screened, they can't send a transaction. Nullfill doesn't need them to: after the deadline, anyone can unwind it, and the money goes to the recovery address named when it opened, never to whoever pressed the button. This page gives you a throwaway testnet wallet that has never been party to any of these escrows. Its only job is paying the gas.

02 Try to break it

Five ways to steal or strand the money. Run them against the live contract.

Each attack is sent to the deployed contract as a call, from the same stranger wallet. A call executes the real code but changes nothing, so you can run these as often as you like. Each one should be refused with the exact error the contract defines for it.
